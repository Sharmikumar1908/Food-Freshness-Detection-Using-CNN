A COLLEGE DEEP LEARNING PROJECT

Food recognition,
made approachable.

FoodLens explores how transfer learning can turn an everyday food photo into a useful starting point for learning about nutrition.

◎

Project objective

Build a web application that preprocesses an uploaded food image, classifies it with a transfer-learned image model, and estimates calories using a reference nutrition table and a user-provided serving quantity.

✳

Model

MobileNetV2 initialized with ImageNet weights, followed by a custom classification head. It is trained and optionally fine-tuned on the chosen food classes.

⌘

Technology

Python, TensorFlow/Keras, Flask, Pillow, NumPy, scikit-learn, Matplotlib, SQLite, HTML, CSS and JavaScript.

▧

Dataset

FooDD on IEEE DataPort is the primary dataset source. Prepare the downloaded images and genuine labels into train, validation and test splits; no dataset images or labels are fabricated here.

!

Limitations

Predictions depend on dataset coverage, image quality and model performance. A single image does not reveal actual portion mass, hidden ingredients or preparation method. Calories are approximate reference estimates, not medical advice or exact image-based measurements.

Evaluation status

No trained model or evaluation metrics are bundled with this starter project. Accuracy, confusion matrix, classification report and loss/accuracy curves are generated only after you train and evaluate on your own real dataset.
